# TECHFEST NEXUS

A responsive, futuristic Techfest landing page with CSS 3D orbital art, pointer-reactive movement, scroll reveals, event portals, timeline, and mobile layouts.

## Run locally
Open `index.html` in a modern browser.

## Deploy with GitHub Pages
1. Create a **public** repository named `techfest-nexus`.
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for the published URL shown in Settings → Pages.
